## 🧠 Engineering Philosophy

I don't want to simply know **how** something works.

I want to understand **why** it works.

When I learn something new, I try to think beyond the abstraction:

```text
             ┌──────────────────────┐
             │     Learn Something  │
             └──────────┬───────────┘
                        ↓
             ┌──────────────────────┐
             │   Understand "Why"   │
             └──────────┬───────────┘
                        ↓
             ┌──────────────────────┐
             │    Build Something   │
             └──────────┬───────────┘
                        ↓
             ┌──────────────────────┐
             │     Break / Debug    │
             └──────────┬───────────┘
                        ↓
             ┌──────────────────────┐
             │     Understand More  │
             └──────────┬───────────┘
                        ↓
             ┌──────────────────────┐
             │       Improve        │
             └──────────────────────┘
```

I believe the fastest way to truly understand a concept is to **use it, question it, and build with it**.
